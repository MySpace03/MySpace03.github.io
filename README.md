# Amin Shavani — Portfolio

A responsive personal portfolio highlighting my experience in data analytics and data engineering, selected projects, technical skills, education, and contact information.

## View the website

Open `index.html` in a browser, or start a local server from this folder:

```powershell
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Features

- Responsive layout for desktop and mobile
- Black-and-green theme with a saved light/dark mode preference
- Sticky, glass-style capsule navigation
- Animated project category filters and scroll reveals
- Résumé download
- Links to project repositories and professional profiles

## Customization

- Update portfolio content and project links in `index.html`.
- Adjust visual styles, responsive breakpoints, and animations in `assets/css/portfolio.css`.
- Update theme switching, navigation, and project filtering behavior in `assets/js/portfolio.js`.
- The résumé download button links to the PDF in the project root.
